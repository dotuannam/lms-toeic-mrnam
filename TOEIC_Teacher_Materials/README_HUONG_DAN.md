# THƯ MỤC TÀI LIỆU ĐỀ THI DO THẦY ĐỖ TUẤN NAM BIÊN SOẠN
**Hệ thống LMS TOEIC MR.NAM — Khung Tiếp Nhận Tài Liệu Chuẩn ETS**

Thư mục này được tạo riêng để Thầy Nam bỏ các file tài nguyên (Hình ảnh, PDF, Audio và Đáp án) do Thầy trực tiếp biên soạn hoặc trích xuất từ đề thi chuẩn ETS. Trợ lý AI sẽ tự động đọc các file từ thư mục này và tích hợp trực tiếp vào trang thi trên Web LMS khi Thầy yêu cầu.

---

## 📁 CẤU TRÚC CÁC THƯ MỤC CON

### 1. 🎧 `TOEIC_Teacher_Materials/audio/`
- **Mục đích:** Chứa các file âm thanh bài nghe Listening Part 1, 2, 3, 4.
- **Định dạng hỗ trợ:** `.mp3`, `.wav`, `.m4a`
- **Quy tắc đặt tên gợi ý:**
  - File trọn bộ: `listening_full.mp3`
  - Hoặc từng Part riêng: `part1_listening.mp3`, `part2_listening.mp3`, `part3_listening.mp3`, `part4_listening.mp3`

---

### 2. 🖼️ `TOEIC_Teacher_Materials/images/`
- **Mục đích:** Chứa hình ảnh minh họa cho phần thi Part 1 (Photographs) hoặc các biểu đồ Part 3, Part 4, Part 7.
- **Định dạng hỗ trợ:** `.jpg`, `.jpeg`, `.png`, `.webp`
- **Quy tắc đặt tên gợi ý:**
  - `part1_q1.jpg`, `part1_q2.jpg`, ...
  - `chart_part3.png`, `table_part7.jpg`

---

### 3. 📄 `TOEIC_Teacher_Materials/pdf/`
- **Mục đích:** Chứa toàn bộ đề thi định dạng PDF (Test Booklet, Answer Sheet chuẩn IIG/ETS, hoặc Ebook tài liệu giải thích).
- **Định dạng hỗ trợ:** `.pdf`
- **Quy tắc đặt tên gợi ý:**
  - `TOEIC_Placement_Test_Booklet.pdf`
  - `Bang_Dap_An_Va_Giai_Thich.pdf`

---

### 4. 📝 `TOEIC_Teacher_Materials/transcript_va_dap_an/`
- **Mục đích:** Chứa file Word (`.docx`) hoặc văn bản (`.txt`, `.md`) ghi chép Transcript lời thoại, câu hỏi trắc nghiệm, đáp án đúng và lời giải chi tiết.

#### Mẫu định dạng câu hỏi gợi ý (Thầy có thể viết theo mẫu này để AI nạp tự động nhanh nhất):
```markdown
### CÂU HỎI MẪU:
- Phần thi: Part 5 (hoặc Part 1, 2, 3, 4, 6, 7)
- Câu hỏi: Ms. Chen reviewed the quarterly financial report _______ before submitting it.
- Lựa chọn A: careful
- Lựa chọn B: carefully
- Lựa chọn C: care
- Lựa chọn D: carefulness
- Đáp án đúng: B
- Giải thích: Cần trạng từ thể cách bổ nghĩa cho động từ "reviewed".
- Cấp độ: Foundation / 550+ / 650+
```
